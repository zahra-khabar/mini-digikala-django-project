# 🛍️ دیجی‌کالا — بازارگاه آزمایشی جنگو

پروژهٔ تمرینی «دیجی‌کالا»: یک آنلاین‌شاپ کوچک با سه نقش مشتری، فروشنده و ادمین.
مشتری‌ها محصولات را مرور و با کیف پول آزمایشی خرید می‌کنند؛ فروشنده‌ها فروشگاه می‌سازند و محصولاتشان را مدیریت می‌کنند.

## امکانات

- **مشتری:** جست‌وجو و فیلتر دسته‌بندی محصولات، مشاهدهٔ فروشگاه‌ها، سبد خرید (افزودن، تغییر تعداد، حذف)، شارژ کیف پول آزمایشی، پرداخت، صفحهٔ تشکر و تاریخچهٔ سفارش‌ها
- **فروشنده:** ساخت و ویرایش فروشگاه، افزودن/ویرایش/حذف محصول با تصویر (PNG، JPEG، WebP و HEIC)، قیمت، موجودی و دسته‌بندی، پنل فروشنده با نمایش موجودی حساب فروشگاه
- **ادمین:** مدیریت کاربران، فروشگاه‌ها، دسته‌بندی‌ها، محصولات و سفارش‌ها از پنل جنگو
- مدیریت موجودی: محصول ناموجود به سبد اضافه نمی‌شود و موجودی هنگام پرداخت به‌صورت اتمیک کم می‌شود
- محصولاتی که در سفارش‌ها هستند قابل حذف نیستند تا سابقهٔ خرید حفظ شود

## فناوری‌ها

Python 3.14 · Django 6.1 · PostgreSQL (psycopg 3) · Pillow + pillow-heif · python-decouple · فونت وزیرمتن

## راه‌اندازی

۱) محیط مجازی و وابستگی‌ها:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

۲) فایل محیطی (نام دیتابیس `digikala_db`، پورت `5432` و درایور psycopg بین اعضای تیم یکسان است):

```bash
cp .env.example .env
```

۳) ساخت دیتابیس (PostgreSQL باید در حال اجرا باشد):

```bash
createdb digikala_db
```

۴) جدول‌ها و اجرا:

```bash
python manage.py migrate
python manage.py createsuperuser    # اختیاری
python manage.py runserver
```

آدرس <http://127.0.0.1:8000/> — پنل مدیریت: <http://127.0.0.1:8000/admin/>

۲۴ تست جریان خرید، موجودی، سبد خرید، آپلود تصویر و کنترل دسترسی‌ها. تست‌ها یک دیتابیس

## مسیرهای اصلی

| مسیر | توضیح |
| --- | --- |
| `/` | صفحهٔ اصلی: محصولات جدید، جست‌وجو و فیلتر دسته‌بندی |
| `/stores/` و `/stores/<id>/` | فهرست فروشگاه‌ها و صفحهٔ فروشگاه (مالک: افزودن/ویرایش/حذف محصول) |
| `/stores/create/` و `/stores/<id>/edit/` | ساخت و ویرایش فروشگاه (فروشنده) |
| `/seller/` و `/customer/` | پنل فروشنده و پنل مشتری |
| `/payment/` | شارژ آزمایشی کیف پول |
| `/cart/` | سبد خرید |
| `/cart/checkout/` و `/cart/success/<id>/` | پرداخت و صفحهٔ تشکر |
| `/orders/` | تاریخچهٔ سفارش‌ها |
| `/accounts/signup/`، `/accounts/login/`، `/accounts/logout/` | ثبت‌نام، ورود و خروج |
| `/admin/` | پنل مدیریت جنگو |

## منطق پرداخت آزمایشی

- کسر از مشتری، واریز به فروشگاه‌ها، کاهش موجودی محصولات، ثبت سفارش و خالی‌کردن سبد
  داخل یک تراکنش اتمیک انجام می‌شوند.
- قفل‌ها به ترتیب مشتری → اقلام سبد → محصولات (بر اساس کلید اصلی) → فروشگاه‌ها گرفته می‌شوند.
- قیمت و موجودی هنگام پرداخت دوباره از پایگاه داده خوانده می‌شود؛ مقادیر ارسالی از مرورگر مبنای خرید نیستند.
- اگر موجودی کالا یا کیف پول کافی نباشد، هیچ تغییری ثبت نمی‌شود.

## ساختار پروژه

| مسیر | مسئولیت |
| --- | --- |
| `config/` | تنظیمات (پکیج settings با تفکیک dev/prod)، URL اصلی و صفحهٔ اصلی |
| `accounts/` | ثبت‌نام، ورود/خروج، پروفایل مشتری/فروشنده و کیف پول |
| `stores/` | فروشگاه، دسته‌بندی، محصول، مدیریت فروشنده و دادهٔ نمونه |
| `orders/` | سبد خرید، پرداخت، سفارش‌ها و صفحهٔ تشکر |
| `templates/` و `static/` | قالب‌ها و استایل مشترک |
